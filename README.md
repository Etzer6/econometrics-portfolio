# Macroeconometrics Project

This project was developed as part of a Master’s degree coursework in Applied Economics at the University of Lille.

The objective of this project is to apply macroeconometric and statistical methods to analyze macroeconomic dynamics and economic forecasting models.

## Main Topics
- Time series analysis
- Macroeconomic modeling
- Econometric estimation
- Forecasting methods
- Statistical interpretation

## Tools Used
- R
- Econometric and statistical methods
- Data visualization

## Files Included
- R code
- Final report (PDF)
- Dataset

This project reflects practical skills in macroeconometrics, quantitative analysis and applied economic modeling.
