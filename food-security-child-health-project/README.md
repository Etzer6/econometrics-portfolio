# Household Food Security and Child Health Analysis

## Project Overview
This collaborative academic project was developed as part of the Master’s degree in Applied Economics at the University of Lille.

The project analyzes the relationship between household food insecurity and the prevalence of diseases among children using statistical and socio-economic data.

The study explores:
- Household food expenditures
- Food diversity
- Agricultural production
- Child health indicators
- Malnutrition risks
- Economic access to food

## Objectives
The objective of this project is to better understand how food insecurity affects children's health and living conditions.

The analysis highlights the interactions between:
- Poverty
- Nutrition
- Public health
- Household economic vulnerability
