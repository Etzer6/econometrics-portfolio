# Macroeconometrics Project 2

This project was completed as part of a group assignment by Jean Etzer Charles and Moussa Coulibaly.

## Project Overview

This project was developed during the Master's program in Applied Economics at the University of Lille. The objective of this work is to apply macroeconometric and time-series analysis techniques using R.

The project covers several important econometric concepts, including:

* Autoregressive models (AR)
* Moving Average models (MA)
* ARMA models
* Stationarity analysis
* Autocorrelation analysis
* Maximum Likelihood Estimation (MLE)
* Ljung-Box test
* Augmented Dickey-Fuller (ADF) unit root test
* Trend and cycle decomposition

---

## Main Topics Covered

### 1. Simulation and Estimation of an AR(3) Process

* Verification of stationarity conditions
* Simulation of a stationary AR(3) process
* Estimation of parameters using Maximum Likelihood Estimation
* Analysis of residual variance and model performance

### 2. Identification of a Time-Series Process Using ACF and PACF

* Computation of sample mean
* Interpretation of ACF and PACF graphs
* Identification and estimation of an AR(1) model
* Residual diagnostics using the Ljung-Box test

### 3. ARMA(1,2) Theoretical Analysis

* Derivation of autocorrelation properties
* Proofs related to the autocorrelation function
* Time-series theoretical interpretation

### 4. Simulation of an MA(1) Process

* Simulation of a moving average process
* Construction of the conditional log-likelihood
* Parameter estimation using Maximum Likelihood methods

### 5. Trend and Cycle Decomposition

* Logarithmic transformation of U.S. population data
* Estimation of a quadratic deterministic trend
* Residual analysis
* Ljung-Box autocorrelation testing
* Augmented Dickey-Fuller unit root testing
